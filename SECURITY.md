# Security Policy

Rouvr is early-stage (0.x) development software. Until the public default
branch is cut, the supported product branch is `rouvr-development`; after
release, prefer the tagged `v0.x` line on the repository default branch.

Please **do not open a public issue** for vulnerabilities. Report privately via GitHub's "Report a vulnerability" (Security tab → Advisories) on this repository. We aim to acknowledge within 5 working days.

Never commit real API keys; `.env` is git-ignored.
