# Rouvr v0.1.0 — release notes (draft)

Status: prepared on `rouvr-development`. Verified locally:
`make test-public` → **670 passed, 7 skipped**; hygiene clean; archive
extract + `make setup` succeeded under a minimal env.
**Do not tag until** a maintainer explicitly cuts the tag (and merges /
retargets the public default branch).

## What ships

Rouvr-lite as the supported open-source product:

- `ledger/` — WorkHub-lite (SQLite FastAPI): tasks, contracts, evidence,
  receipts, chat intake, plans, sealing.
- `web/` — operator workspace (Next.js) proxied same-origin to the ledger.
- Sealing helpers under `rouvr/` used by approve-time hidden suites.

`core/`, `workers/`, `lane/`, Temporal demos remain in the tree as
**experimental** and are not part of the quickstart.

## Highlights since the public cut

- Owner UI matches ledger roles: no session claim/grant create; Approve
  requires `needs_review` + contract + evidence + `head_verdict=pass`.
- Cookie sessions refill username and CSRF via `GET /auth/session`.
- Knowledge Verify uses the owner review path.
- Private path/password defaults scrubbed; hygiene fails on `hackathon` /
  private-org leftovers; git grants documented beside workspaces.
- NOTICE, Contributor Covenant, MIT metadata; stranger-facing web README.

## Known limitations

- No in-UI worker: claim / attempts / results need the stack token.
- Board polls tasks (3s) and uses a closed events snapshot; task detail
  tails live SSE.
- Stub model cannot author plans or seals; set Meta/Ollama/OpenRouter.
- Default GitHub branch may still be `main` until maintainers merge and
  retarget the default; clone with `-b rouvr-development` until then.
- Not production-hardened.

## Release checklist

1. `bash scripts/hygiene.sh` clean.
2. `make test-public` green on a clean checkout with only `.env.example`
   secrets exported.
3. Fresh archive/`git clone -b rouvr-development` → `make setup` succeeds.
4. Manual smoke: `make ledger`, register demo tenant/project, `pnpm start`
   in `web/`, login as `admin`, open board (observe-only without a worker).
5. Merge product branch to the public default (or set default to the
   product branch); retarget the CI badge if needed.
6. Tag `v0.1.0` on the verified commit and publish a GitHub Release using
   this note. **Tag only on explicit maintainer ask.**

## Rotate / ops follow-ups

- Any password that ever matched the deleted local helper
  `refresh_workhub_api_token.py` must be rotated out-of-band.
- Prefer setting `ROUVR_SPEC_REPO` / `R10_REPO` to your own scratch repo;
  no private org is defaulted anymore.
