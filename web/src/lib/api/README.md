# Typed API client (`web/src/lib/api/`)

- `openapi.json` — snapshot of the ledger FastAPI spec. Regenerate with
  `python scripts/export_ledger_openapi.py` (from the repo root).
- `schema.d.ts` — generated by `pnpm --filter web gen:api`. Do not edit.
- `client.ts` — typed `ledger` client (openapi-fetch) plus `requestJson`,
  the only `fetch()` call in `web/src`. All screens must use this module;
  raw `fetch` elsewhere is banned by `eslint.config.mjs`.
- `contact.ts` — typed helper for the same-origin `POST /api/contact` route.

Ledger base URL defaults to `http://127.0.0.1:8221`; override with
`NEXT_PUBLIC_ROUVR_API_BASE_URL`.
