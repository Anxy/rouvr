# Typed API client (`web/src/lib/api/`)

- `openapi.json` — snapshot of the ledger FastAPI spec. Regenerate with
  `python3 scripts/export_openapi.py` (from the repo root).
- `schema.d.ts` — generated by `pnpm --filter web gen:api`. Do not edit.
- `client.ts` — typed `api` client (openapi-fetch) bound to the generated
  schema, plus `submitContact` for the same-origin contact route (also via
  openapi-fetch, so no screen ever calls `fetch` directly).

Ledger base URL defaults to `http://127.0.0.1:8221`; override with
`NEXT_PUBLIC_API_BASE_URL`.
